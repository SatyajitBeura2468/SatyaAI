# Llama 3.2 licensing note

SatyaAI includes browser-local inference options based on Llama 3.2 model variants. The Llama 3.2 Community License requires, among other conditions, a prominent **“Built with Llama”** attribution when making a product or service using Llama Materials available, and specifies an attribution notice for copies of Llama Materials that are distributed.

SatyaAI displays “Built with Llama” in the interface and README. The repository root NOTICE file contains Meta's Llama 3.2 attribution statement and links to the official license text.

The current repository does not commit Llama model weights. Browser inference retrieves model assets through the WebLLM model runtime. Before bundling or redistributing Llama weights, model files, or derivative materials in a release, include the full applicable agreement alongside those materials and re-check the license, Acceptable Use Policy, model-specific notices, and any distribution terms.

Official source: [Meta Llama 3.2 model repository and license](https://huggingface.co/meta-llama/Llama-3.2-3B-Instruct/blob/main/LICENSE.txt).

This is an engineering compliance note, not legal advice. Verify the license for each selected model and runtime artifact before distribution.
